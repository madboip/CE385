1. Callback (ex1-callback.js)
ส่ง Error เป็นตัวแรก: ใช้รูปแบบ (error, result) เสมอ  
ใส่ return หน้า callback: เพื่อเบรกฟังก์ชันไม่ให้โค้ดไหลไปรันบรรทัดล่างต่อ ป้องกันการรันเบิ้ล  
จุดตาย: ถ้าลืมเช็ค if (error) แล้วฝืนเอาข้อมูลไปใช้ โปรแกรมจะแครช (Crash) ทันที

2. Promise (ex2-promise.js)
คำสัญญา: สำเร็จเรียก resolve() พังเรียก reject()  
การต่อโซ่: ใช้ .then() เป็นขั้นบันได แต่ ห้ามลืม return ในแต่ละขั้นเพื่อส่งค่าต่อไป  
ดัก Error ที่เดียว: ใช้ .catch() ปิดท้ายเป็นท่อระบาย ดักพังได้ทั้งโซ่

3. Async/Await (ex3-async-await.js)
โค้ดหยุดรอจริงๆ: พอใส่ await โค้ดจะหยุดรอ ทำให้เราใช้ try-catch ดักจับ Error ได้เหมือนเขียนโค้ดปกติ  
ทีละตัว vs พร้อมกัน: ใช้ await ในลูปคือรอทีละตัว (ช้า) แต่ถ้าใช้ Promise.all() คือโหลดพร้อมกันหมด (เร็วเท่าตัวที่ช้าสุด)  

4. 4 เครื่องมือดึงข้อมูลพร้อมกัน (ex4-combinators.js)
Promise.all: ต้องรอดครบทุกตัว พังตัวเดียวคือจบ (เหมาะกับโหลดข้อมูลหน้าแรกของเว็บ)  
Promise.allSettled: รอจนจบครบทุกตัว ไม่สนว่าพังหรือรอด (เหมาะกับทำระบบแจ้งเตือนหลายช่องทาง)  
Promise.any: เอาตัวแรกที่สำเร็จ ข้ามตัวที่พังทิ้งไป (เหมาะกับดึงข้อมูลจาก Mirror Server)  
Promise.race: ใครจบก่อนชนะ ไม่สนพังหรือรอด (เหมาะกับทำระบบจับเวลา Timeout)
